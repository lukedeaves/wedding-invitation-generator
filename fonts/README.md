# Bundled fonts

These fonts are used for invitation typography:

- **Great Vibes** — script style for couple names ([OFL](https://openfontlicense.org/))
- **Cormorant Garamond** — body text ([OFL](https://openfontlicense.org/))

Source: [Google Fonts](https://fonts.google.com/)

If font files are missing, the generator falls back to Helvetica.
